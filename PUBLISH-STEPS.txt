🚀 PUBLISH STEPS

=== STEP 1: Create GitHub Repository ===
1. Go to: https://github.com/new
2. Repository name: strava-media-uploader
3. Description: Automated media uploader for Strava activities
4. Visibility: Public (code has no secrets)
5. DO NOT initialize with README
6. Click "Create repository"

=== STEP 2: Push Code ===
Run these commands:

git remote add origin https://github.com/YOUR_USERNAME/strava-media-uploader.git
git push -u origin main

(Replace YOUR_USERNAME with your GitHub username)

=== STEP 3: Deploy to Cloud ===
Choose one:

A) Browserless.io Deployment:
   - Get token from: https://www.browserless.io
   - Set BROWSERLESS_WS_ENDPOINT environment variable
   - Upload sessions/state.json to your server
   
B) Own Server:
   - git clone your-repo
   - npm install
   - Upload sessions/state.json
   - Run: node upload.js "https://url1" "https://url2"

=== STEP 4: Make.com Integration ===
- Create webhook in Make.com
- Your webhook receives URLs
- Call: node upload.js "url1" "url2"
- Script handles download + upload automatically

=== SECURITY REMINDER ===
✅ sessions/state.json is NOT in Git (safe)
⚠️ Upload it separately to your server (keep secret)
